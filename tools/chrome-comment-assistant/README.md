# 评论角度助手（Chrome）

根据当前贴文上下文，按**自定义角色/评论角度**调用大模型生成多条候选评论，从中选一条复制或填入评论框。

## 安装

1. Chrome → `chrome://extensions` → 开启开发者模式  
2. 「加载已解压的扩展程序」→ 选择本目录：`tools/chrome-comment-assistant`

## 配置

打开扩展 → **设置**：

| 项 | 说明 |
|----|------|
| API Key | 必填 |
| API Base | OpenAI 兼容地址，默认通义：`https://dashscope.aliyuncs.com/compatible-mode/v1` |
| 模型 | 如 `qwen-turbo`、`gpt-4o-mini` |
| 条数 | 每次生成 2～8 条 |

也支持其它 OpenAI 兼容网关（把 Base 改成对应 `/v1` 即可）。

## 使用

1. 打开帖子/视频页（可选：先选中一段正文）  
2. 点扩展图标 → 自动读取上下文（可再点「从当前页读取」或手改）  
3. 选角色预设，或改「自定义角度说明」  
4. **生成评论** → 点选一条 → **复制所选** / **填入评论框**

内置角度：理性分析 / 友善互动 / 质疑追问 / 实操经验 / 轻度幽默 / 完全自定义。

## 站点适配

- 优先：当前选区  
- YouTube / B 站 / X(Twitter)：尝试读标题、作者、简介或正文  
- 其它站点：`og:title` / `description` / `article` / `main`  
- 填入：常见评论框选择器；找不到则自动复制到剪贴板

## 注意

- Key 存在本机 `chrome.storage.local`，不会上传到本仓库。  
- 生成内容需自行把关，插件不会自动点「发送」。  
- 部分站点评论框在 Shadow DOM / 动态加载里，填入失败时用复制即可。
